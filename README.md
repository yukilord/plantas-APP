# Herbanário

Aplicação web para acompanhar uma coleção de plantas, regas e cuidados.

## Abrir o site

No Windows, abre uma janela do PowerShell na pasta do projeto e executa:

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

O site abre automaticamente em <http://127.0.0.1:8000/>. Para o fechar, prime
`Ctrl+C` na janela do PowerShell.

Na primeira visita, escolhe **Registar** para criar uma conta. Os dados da
aplicação ficam guardados localmente no navegador.
